A modern and responsive sidebar navigation UI built using HTML, CSS, and basic JavaScript. 
This project demonstrates a clean layout with a side menu and a main content section.

🚀 Features
📂 Sidebar navigation menu
🎨 Clean and modern UI design
📱 Responsive layout (works on different screen sizes)
🖼️ Image-based main content section

🔗 Navigation items like:
Gallery
Shortcuts
Exhibits
Events
Store
Contact
Feedback

🛠️ Technologies Used
HTML5
CSS3
JavaScript (optional for interactions)
